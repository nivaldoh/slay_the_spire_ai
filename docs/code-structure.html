src/twwarhammer3/

Warhammer III

Python controls a real-time custom battle through files shared with the Lua mod.

Start a play job

  1. python -m twwarhammer3 play

    Load options and select a controller.

  2. play()

    Load the scenario and launch or attach.

  3. play_episode()

    Make a fresh controller for each battle.

src/spire/

Slay the Spire

Python plays through complete runs by sending commands to CommunicationMod over a TCP relay.

Start a play job

  1. python -m spire play

    Load seeds and configure the model policy.

  2. play()

    Record the job and iterate over seeds.

  3. play_run()

    Open the bridge and launch a fresh JVM for the seed.
